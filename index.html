Seus Perfis

Como conectar o WhatsApp

É muito fácil criar um grupo no WhatsApp para mandar as suas contas! Siga o passo a passo abaixo para que tudo que você mandar lá caia no seu app de finanças em tempo real:

Passo 1: Criando a ponte de automação

Você pode usar ferramentas de integração de WhatsApp (como a Z-API ou Evolution API) em conjunto com plataformas de automação gratuitas como o Make.com:

  • Crie uma conta gratuita no Make.com;
  • Toda vez que uma nova mensagem de áudio, texto ou imagem for detectada no grupo, o Make fará a ponte direto para a API de inteligência artificial;
  • Uma vez estruturado o JSON, o Make salva na memória local do app ou envia como uma requisição para a sua base de dados.

Passo 2: Integrando pelo Painel

Ao ativar sua API Key do Gemini nas configurações deste app, a própria inteligência artificial estruturará os dados de forma impecável direto da sua tela do iPhone!
